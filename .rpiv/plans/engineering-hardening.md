## Phase 2 — CI (two workflows)

- `check.yml` on PR: `npm ci` (node 22) → `npm run fmt:check` →
  `npm run lint:css` → `npx eslint .` → `npx html-validate '**/*.html'`
  (add `html-validate@^11.10.0` as devDependency) → vendor-sync guard
  (`npm run build:vendor && git diff --exit-code vendor/`) → fonts-drift
  job (`node scripts/download-fonts.mjs && git diff --exit-code assets/fonts/`)
  → `lycheeverse/lychee-action@v2` with `GITHUB_TOKEN`.
- Extend `scripts/build-vendor.mjs` with explicit copy steps for the static
  copies (`vendor/three.min.js`, `vendor/atom-one-dark.css`,
  `vendor/prism-okaidia.css`) so the sync guard covers all vendor artifacts.
- `deploy.yml` on push to main: `actions/configure-pages@v5` →
  `actions/upload-pages-artifact@v5` (path `.`) →
  `actions/deploy-pages@v5`; permissions `id-token: write`,
  `contents: read`; concurrency guard.
- `renovate.json`: add a `packageRules` group for vendor runtime deps
  (`prismjs`, `highlight.js`); `ignoreDeps: ["three"]` until the ROADMAP
  work package runs.
